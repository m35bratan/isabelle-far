Première utilisation ? Il faut créer une clé d'accès (une seule fois) :
  1. Ouvrez cette page GitHub (connectez-vous si besoin)
  2. Token name : écrivez Site Isabelle
  3. Expiration : choisissez No expiration
  4. Repository access : cochez Only select repositories puis choisissez isabelle-far
  5. Permissions → Repository permissions → Contents : choisissez Read and write
  6. Cliquez sur Generate token, puis copiez la clé affichée
  7. Collez-la ci-dessous — elle reste sur votre appareil, elle n'est jamais partagée
